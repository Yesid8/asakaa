### 12. Optimistic UI Updates
**Status**: Not started

**Actions to Optimize**:
- Card creation: Show immediately, sync in background
- Card updates: Apply locally, rollback on error
- Card deletion: Remove from UI, restore on error
- Drag & drop: Update position immediately

**Implementation Pattern**:
```tsx
// Optimistic update
const optimisticCard = { ...newCard, id: `temp-${Date.now()}` }
setCards([...cards, optimisticCard])

// Background sync
try {
  const savedCard = await api.createCard(newCard)
  setCards(cards => cards.map(c => c.id === optimisticCard.id ? savedCard : c))
} catch (error) {
  // Rollback
  setCards(cards => cards.filter(c => c.id !== optimisticCard.id))
  showError('Failed to create card')
}
```
